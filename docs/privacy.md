# Privacy

## Data Collection

The system collects only the minimum data required:

- Account information (name, email)
- Resume content (user-provided or imported)
- Job descriptions (user-provided)
- Templates (user-uploaded)
- AI usage metrics (anonymized)

## Consent

Users must provide explicit consent for:

- AI processing of resume data
- LinkedIn data import
- Data storage and processing

Consent can be withdrawn at any time via account settings.

## Data Retention

| Data Type | Retention Period |
|-----------|-----------------|
| Active accounts | Until account deletion |
| Deleted accounts | 30 days (grace period) |
| Export files | 7 days |
| AI usage logs | 90 days (anonymized) |
| Audit logs | 1 year |

## User Rights

Users can:

- Export all personal data
- Delete their account and associated data
- Withdraw AI processing consent
- Request data correction
- Access processing history

## AI Training

- No resume content is used for AI model training
- Gemini API calls are not used for training by default
- Users are notified if this policy changes

## Data Sharing

- Resume data is never shared with third parties
- LinkedIn import data stays within the application
- AI processing uses Google Gemini API (data not used for training)

## Compliance

The system is designed to support:

- **LGPD** (Brazil) — User rights, consent, data portability
- **GDPR** (EU) — Data protection, right to erasure, data portability
- Applicable privacy regulations in supported regions

## Technical Measures

- Encryption in transit (TLS 1.3)
- Encryption at rest
- Database backup encryption
- Secure data deletion
- Access control and audit logging
- Personal data redacted from logs
